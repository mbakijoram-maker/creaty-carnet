# Carnet CREATY

Carnet de bord interne de JP CREATY (Joram & Plam's) : commandes, dépenses personnelles par type et recettes de l'entreprise.

- `index.html` : l'application (base SQLite qui tourne dans le navigateur avec sql.js).
- `schema.sql` : le schéma de la base (tables, données de départ, vues).

Les données restent dans le navigateur de chaque appareil. Rien n'est envoyé sur internet.
Pour sauvegarder ou partager : onglet **Sauvegarde** → exporter le fichier `.db`, puis l'importer sur l'autre appareil.
